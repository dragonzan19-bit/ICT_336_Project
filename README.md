# Credit Card Default Risk Explorer

An educational Machine Learning project that estimates the probability of credit-card default using the UCI Default of Credit Card Clients dataset.

> This project is for learning and demonstration only. It is not financial advice and must not be used to make real lending decisions.

## Requirements

- Python 3.10 or newer recommended
- Internet connection for the first dataset download
- Terminal

## Setup on macOS

Open Terminal and move into the project folder:

```bash
cd ~/Desktop/Credit-Default-Project
```

Create and activate a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

On macOS, install XGBoost's OpenMP runtime:

```bash
brew install libomp
```

Install dependencies:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Train the model

Run this once from the project root:

```bash
python train_model.py
```

The script downloads UCI dataset ID 350, prepares the data, creates a stratified
train/test split, and trains Logistic Regression, Random Forest, and XGBoost
pipelines. It writes the Logistic Regression pipeline used by the app, a separate
XGBoost pipeline, and comparable held-out metrics for all three models to
`data/model_comparison.csv`.

The first run requires an internet connection.

## Start the Streamlit app

After training completes:

```bash
streamlit run app.py
```

Open the local URL shown in Terminal (normally http://localhost:8501).

## Appearance

Use the app's top-right menu to select **System**, **Light**, or **Dark**.
The app's layout and form controls use Streamlit theme colors so they adapt to
the selected appearance.

## Important implementation notes

- Preprocessing is part of the saved scikit-learn pipeline. The app sends raw feature values in the expected columns and order.
- Numerical columns are median-imputed and standardized.
- Categorical columns are most-frequent-imputed and one-hot encoded.
- The train/test split is stratified and uses a fixed random seed.
- The 0.50 threshold is a demonstration default, not a validated lending threshold.
- The exported metrics describe only this held-out test split and do not establish suitability for real-world credit decisions.
- XGBoost is included as a comparison model; the app's individual predictions continue to use Logistic Regression.
